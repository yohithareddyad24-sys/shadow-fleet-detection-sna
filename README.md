# Shadow Fleet Detection — Maritime Network Analysis & Path Optimization

A hybrid maritime intelligence system combining **Satellite AIS Data Ingestion**, **Social Network Analysis (SNA)**, and **Ant Colony Optimization (ACO)** to detect, track, and score anomalous vessel behaviors, ship-to-ship (STS) rendezvous transfers, and potential shadow fleet supply chains.

---

## 1. Important Ethical Disclaimer

> **IMPORTANT NOTICE:** Synthetic illustrative data is utilized for testing and algorithmic verification. No real vessels or maritime entities are accused of illicit activities. Metrics generated by this system (centrality indices, composite risk scores, and ACO heuristic pathways) do **NOT** prove illicit operations, sanctions evasion, or wrongdoing. All scores serve exclusively as exploratory triage tools to assist qualified maritime analysts in prioritizing investigative workloads.
